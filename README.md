# 日本ライブカメラマップ

**▶ 公開中: https://ykato27.github.io/japan-cam-map/**

日本中の定点カメラを日本地図（国土地理院タイル）の上に置き、ブラウザでそのまま見られるようにするサイトです。

- マーカーをタップすると、その地点のライブ映像（YouTube埋め込み）または最新の静止画（自動更新）がポップアップで表示されます
- YouTubeはクリック再生方式（開いただけでは広告も映像も始まりません）
- カテゴリ絞り込み（都市／山・自然／河川／観光地／港／空港／動物）とキーワード検索つき
- 収録カメラは全件、実在と配信状態を検証済みのものだけ（2026-10-25 時点で 113 件）

静的サイト（`index.html` + `cameras.js`）なので、どこに置いても動きます。GitHub Pages で `main` ブランチから公開しています。

### Cloudflare Pages（無料）
1. Cloudflare にログイン → Workers & Pages → Create → Pages → Connect to Git
2. このリポジトリを選択（フレームワークなし、ビルドコマンドなし、出力ディレクトリは `/`）
3. `*.pages.dev` のURLで公開されます。独自ドメインも無料で割り当て可能

## データについて

カメラデータは `cameras.js` の `window.CAMERAS` 配列です。1件は次の形式です。

```js
{ name, pref, city, lat, lon, category, type: "youtube" | "image", videoId?, image?, provider, source }
```

- `youtube`: YouTubeの24時間ライブ配信を埋め込み表示
- `image`: 国土交通省「川の防災情報」等の公開静止画URLを直接表示（60秒ごとに再取得）

映像・画像の著作権は各配信元に帰属します。本サイトは配信元の公開ページへのリンクと、公開されている埋め込み／画像URLの表示のみを行います。

座標は設置地点のおおよその位置です。河川カメラは配信元の住所情報をもとに置いているため、数百m程度ずれる場合があります。

## 注意

定点カメラは配信停止・URL変更が頻繁に起きます。特に河川カメラは「調整中」等の差し替え画像に切り替わることがあるため、定期的な死活チェックが必要です（検証時も12件中6件が停止中でした）。
