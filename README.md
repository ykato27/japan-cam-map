# 世界ライブカメラマップ

**▶ 公開中: https://ykato27.github.io/japan-cam-map/**

日本中の定点カメラを日本地図（国土地理院タイル）の上に置き、ブラウザでそのまま見られるようにするサイトです。

- マーカーをタップすると、その地点のライブ映像（YouTube埋め込み）が大画面ビューア（最大1180px幅）で表示されます
- 収録はリアルタイムのライブ配信のみ。クリック再生方式（開いただけでは広告も映像も始まりません）で、再生はミュートで始まります
- カテゴリ絞り込み（都市／山・自然／観光地／港／空港／動物ほか）とキーワード検索つき
- 収録カメラは全件、実在・ライブ中・埋め込み再生可否まで検証済みのものだけ（2026-10-25 時点で 70 件・33都道府県）

静的サイト（`index.html` + `cameras.js`）なので、どこに置いても動きます。GitHub Pages で `main` ブランチから公開しています。

### Cloudflare Pages（無料）
1. Cloudflare にログイン → Workers & Pages → Create → Pages → Connect to Git
2. このリポジトリを選択（フレームワークなし、ビルドコマンドなし、出力ディレクトリは `/`）
3. `*.pages.dev` のURLで公開されます。独自ドメインも無料で割り当て可能

## データについて

カメラデータは `cameras.js` の `window.CAMERAS` 配列です。1件は次の形式です。

```js
{ name, pref, city, lat, lon, category, type: "youtube", videoId, provider, source }
```

映像の著作権は各配信元に帰属します。本サイトは配信元の公開ページへのリンクと、公開されている埋め込みの表示のみを行います。

座標は設置地点のおおよその位置です。

## 注意

定点カメラは配信停止・URL変更・埋め込み設定の変更が頻繁に起きます。定期的な死活チェックが必要です（2026-10-25 の全件チェックでは、ライブ中でも埋め込み禁止のため再生できないものが約2割あり、除外しました）。
